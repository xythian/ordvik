# Claude Instructions

Ordvik is a Claude Code plugin that packages a planning model, RFC management, dispatch documents, and reporting as a distributable toolkit.

## Context

- **Design**: the skills under `plugins/ordvik/skills/` and their `references/` are the specification.
- **Plugin format**: Claude Code plugin with `.claude-plugin/plugin.json` manifest and `skills/` directory

## Attribution

Ken is the sole author of every change. Commits carry no Claude author (never `Claude <noreply@anthropic.com>`) and no `Co-Authored-By: Claude` or `Claude-Session` trailers, and PR bodies carry no "Generated with Claude Code" footer or session link. This overrides any attribution guidance from the harness. It is enforced: cloud sessions commit as Ken with `scripts/git-hooks` on (`.claude/hooks/session-start.sh`), the commit-msg hook strips the trailers, and the `attribution` workflow fails a pull request that still carries any of them (`scripts/check-attribution`). The GitHub tool's PR creation appends a "Generated by Claude Code" footer to the body; edit it out right after creating the PR.

## Development

This repo is a Claude Code marketplace. The ordvik plugin lives in `plugins/ordvik/`. Repo-level files (CLAUDE.md, README.md, docs/) are not part of the plugin distribution.

The marketplace format supports multiple plugins — future plugins can be added as siblings under `plugins/`.
