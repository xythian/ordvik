# Thread Registry

All known work threads. Every thread listed here must be accounted for in planning — if it has no activity, that itself is noted. Silent drops are the failure mode we guard against.

## Status Definitions

- **active** — work is happening or planned for the near term
- **stable** — working in production, no planned changes
- **parked** — intentionally set aside, will revisit when conditions change
- **dormant** — inactive, no current plans to resume
